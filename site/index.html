PlaceRoot

live map demo

An MCP server that answers spatial questions from Overture Maps open data — queried live from the public GeoParquet release with DuckDB. No API key. No vendor platform. Every answer sized for an agent's context window, not a browser.

keyless Overture-native token-budgeted no ETL MIT licensed

4What's actually in it

  • Keyless. Queries run directly against Overture's public S3 GeoParquet release with DuckDB — no signup, no API key, no vendor platform on the critical path.
  • Fresh, not a stale snapshot. Every place carries Overture's operating_status and a confidence score, contributed by Meta, Uber, TomTom, and others — an agent can reason about whether a place is actually still open.
  • Token-budgeted by design. Every tool response is built to fit roughly 2K tokens; when a result would blow past that, the response is truncated (rows dropped nearest-first-preserved, then optional fields stripped) and says so with truncated: true and omitted_count, rather than silently dumping more than an agent can use.
  • A local tile cache. The first query touching a 1°×1° tile materializes it to disk; every later query touching that tile reads local parquet instead of rescanning S3 — the design target is warm queries under 500ms, and it keeps working if the network doesn't.
  • GERS ids in every response. Each place carries Overture's stable GERS identifier — a cross-session, cross-tool reference an agent can hold onto and resolve later, instead of re-searching by name and hoping for the same match.
  • No ETL. There's no intermediate database or import job — every query reads Overture's GeoParquet directly, with bbox column pushdown to prune row groups.
  • MIT licensed. No usage tier, no metered key.
