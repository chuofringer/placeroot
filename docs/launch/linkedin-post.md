# LinkedIn launch post

Sharing a side project I've been hacking on over the past few weekends: PlaceRoot 🗺️ (https://placeroot.dev)

It's an MCP server that lets AI agents answer real location questions — what's nearby, how do I get there, what's in this neighborhood — all from open data.

No API key, no signup.

The fun part: the whole thing was built by agents running in continuous loops 🤖 with minimal human intervention from me.

MIT licensed, works with Claude Code, Claude Desktop, Cursor, Codex, Grok — anything that speaks MCP.

💻 Repo: https://github.com/chuofringer/placeroot
