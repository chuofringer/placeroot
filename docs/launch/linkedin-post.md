# LinkedIn launch post

Sharing an open source project I've been working on: PlaceRoot 🗺️

It's an MCP server that lets AI agents answer real map questions — what's nearby, how do I get there, what's in this neighborhood — using open data.

No API key, no signup.

The whole thing was built by agents running in continuous loops 🤖 with minimal human intervention.

MIT licensed, works with Claude Code, Claude Desktop, Cursor, Codex, Grok — anything that speaks MCP.

💻 Repo: https://github.com/chuofringer/placeroot
